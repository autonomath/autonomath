# Autonomath

I make things that make my Mac less annoying. Sometimes they make yours less annoying too.

A few recurring annoyances, a bit of curiosity, and some code. These are the Mac tools that came out of it.

## The tools

| Tool | What it does |
| --- | --- |
| [Android File Transfer](https://autonomath.github.io/android-file-transfer-for-macos/) | Move files between Android and your Mac over USB. |
| [TilePilot](https://autonomath.github.io/TilePilot/) | Window layouts, shortcuts, and work sets for macOS. |
| [SessionRecall](https://autonomath.github.io/SessionRecall/) | Find the AI coding session you remember, across Codex, Claude Code and 14 other agents. |
| [Lock Anyway](https://autonomath.github.io/lock-anyway/) | Idle locking even when other apps keep the Mac awake. |
| [CPU Cap](https://github.com/autonomath/macos-cpucap/releases/latest) | Control how much CPU an application can use. |
| [Log Video Player](https://autonomath.github.io/log-video-player/) | Watch Log footage in Rec.709 colour while preserving the original. |
| [HDR Always On](https://github.com/autonomath/hdr-always-on/releases/latest) | Keep HDR enabled on supported external displays. |

## A few things I care about

- Small tools that solve a real problem.
- Keep the core work on your Mac.
- Clear release notes, signed downloads, and checksums you can verify.

You'll find public source here where available. Log Video Player is distributed through the Mac App Store; its public repository is for its website and support.

Have an idea or found something annoying? Open an issue on the relevant project.
